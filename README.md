# Task Management Application

A full-stack web application developed using Python Flask and PostgreSQL to help users organize, manage, and track their daily tasks efficiently.

## 🌐 Live Demo

**Live Application:** https://task-management-app-vll1.onrender.com

**GitHub Repository:** https://github.com/reshwanth-stack/task-management-app

## 🚀 Features

- User Registration and Login
- Create, Edit, and Delete Tasks
- Task Priority Management (High, Medium, Low)
- Due Date Management
- Task Categories (Work, Study, Personal, Projects, Other)
- Filter Tasks by Category
- Dashboard Statistics
- Overdue Task Tracking
- Task Completion Visualization
- Subtask Management
- Responsive User Interface
- Smooth Scrolling to Create Task Form

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|

| JavaScript | Interactive Features |

| Gunicorn | Production Server |
| Render | Cloud Deployment |

## 📸 Application Overview

The application provides a user-friendly dashboard where users can create tasks, manage priorities, set deadlines, organize categories, and track their progress.

## ☁️ Deployment

The application is deployed on **Render**.

- Backend: Flask
- Database: PostgreSQL
- Web Server: Gunicorn
- Hosting: Render

**Live URL:** https://task-management-app-vll1.onrender.com

## 🎯 Project Objective

The objective of this project is to build a practical task management system that helps users organize daily activities, manage priorities, track deadlines, and improve productivity.

This project demonstrates practical knowledge of full-stack web development, database integration, user authentication, and cloud deployment.
